Reglas de seguridad

  • Solicitar aprobación antes de enviar mensajes, publicar anuncios o cambiar presupuestos.
  • No borrar, sobrescribir ni compartir archivos sin confirmación.
  • Usar permisos mínimos para cada conector y registrar errores.
  • No guardar claves API, contraseñas o tokens en este panel ni en GitHub.
  • Probar primero con datos ficticios y permitir detener ejecuciones.
Conectividad

Integraciones y estado

El panel no solicita ni guarda credenciales. Las conexiones requieren configuración independiente.

Próxima arquitectura

  1. Panel web estático (esta interfaz).
  2. Backend seguro para autenticar usuarios y proteger secretos.
  3. Conector de IA para Claude u otro proveedor.
  4. Conectores OAuth de Google Drive/Gmail/Calendar con permisos mínimos.
  5. Motor de flujos, registro de sesiones y aprobación humana.

Un panel HTML por sí solo no puede realizar automatizaciones de fondo ni acceder de forma segura a cuentas privadas.
